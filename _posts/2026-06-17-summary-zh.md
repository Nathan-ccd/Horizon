**社区讨论**: 评论者反馈不一：一些人认为本地模型在速度和准确性上不如云 API，而另一些人则更喜欢本地模型没有不必要的观点。有用户认为，随着本地模型改进，云提供商的定价能力将受到侵蚀。

## [停止在浏览器会话中使用 JWT](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

一篇广泛传播的 gist 文章认为，JSON Web Tokens（JWT）不应用于基于浏览器的用户会话，理由是安全性和撤销问题。该帖子在开发者社区引发了广泛讨论。 JWT 在 Web 应用中常用于身份验证，但这一批评揭示了其在会话管理设计中的根本缺陷。这场辩论影响了开发者在保护用户会话时如何在 JWT 和传统会话 cookie 之间做出选择。 该 gist 链接了批评 JWT 安全性的资源，包括 Paragon Initiative Enterprises 在 2017 年的一篇文章。评论者指出，通过设置较短的过期时间和刷新令牌可以使 JWT 更安全，但如果没有服务器端状态，撤销仍然是一个挑战。

hackernews · dzonga · 6月16日 16:49 · [社区讨论](https://news.ycombinator.com/item?id=48558147)

**背景**: JSON Web Tokens（JWT）是一种紧凑、URL 安全的令牌格式，用于身份验证和信息交换。它们是自包含的，意味着令牌本身携带用户数据和签名，无需服务器端存储即可验证。相比之下，传统会话 cookie 在客户端存储会话 ID，并在服务器端维护会话状态，使得撤销操作简单直接。这场辩论的核心在于 JWT 的便利性是否超过其安全权衡，特别是在基于浏览器的会话中，令牌撤销困难。

## [quicktok：比 tiktoken 快数倍的精确 BPE 分词器](https://www.reddit.com/r/MachineLearning/comments/1u73c5r/quicktok_a_faster_tokenizer_exact_and/) ⭐️ 8.0/10

quicktok 是一个新的 C++ BPE 分词器，在生成字节完全相同的 token 的同时，比 OpenAI 的 tiktoken 快 2-11 倍，这得益于优化的数据结构和手工编译的预分词器。 分词是 LLM 推理和训练流程中的瓶颈；一个更快的、可直接替换的替代品可以降低许多应用的延迟和成本。 它支持 cl100k、o200k、GPT-OSS、Llama-3 和 Qwen2.5/3 分词器，在 Apple M1 上的基准测试显示，在 The Pile 数据集上原生速度达 121.7 MB/s，而 tiktoken 仅为 13.6 MB/s。

reddit · r/MachineLearning · /u/_casa_nova_ · 6月16日 04:24

**背景**: BPE（字节对编码）是大多数现代 LLM 用于将文本转换为 token ID 的分词算法。tiktoken 是 OpenAI 的官方 Python 分词器，但其性能可能成为瓶颈。quicktok 用手工编译的预分词器替代了通用正则引擎，并使用 2 字节 trie 和密集缓存来减少内存访问。
